# sub2api 2.33.0-relay

## 合并范围

- 新版本分支：`codex/sub2api-v2.33`，独立工作区 `sub2api-v2.33`。
- 发布基线：`acddfddf67206aa4198c05a85af718ecee32ffa6` / `2.32.0-relay`。
- 上游：`Wei-Shaw/sub2api` main `5fc0e486c3f6a8a191b8bd140f39b60457f611cf`，2026-10-08，VERSION `0.2.14`。
- 完整合并自 `efe9aab1e4` 以来的 553 个提交，保留双方历史；上游拆分文件的改动按声明移植到本地已发布的合并布局。
- 原始 `sub2api` 目录及其未提交工具协议改动保留原状。

## 主要更新

- Claude Opus/Sonnet 5.5 兼容、显式结构化输出与工具变更 beta、缓存 TTL 顺序、最终 reasoning effort 计费、Anthropic ping 心跳及流式终态修复。
- OpenAI GPT 6/6.1 与远端模型目录、别名和白名单映射、服务档位、WS 图像用量与分轮定价、取消与终态处理、quota 窗口和粘性调度修复。
- Antigravity 裸 Gemini 思考档位、PDF/图片输入和厂商身份兼容；Grok CLI 1.0.46、SSO consent、限额和空终态处理；OpenCode Go、TypeSafe 等供应商支持。
- 自定义 reasoning effort 倍率、音频和图片分组定价、充值赠送、提现幂等、在途余额预留、订阅事务和密钥创建限制；按次搜索价格与本地每千次价格兼容。
- 上游审计依赖、路由与生命周期完整接入，保留现有默认配置；管理界面的并发、TPS、日志保留、用量和表单竞态修复。密钥实时并发计数和排序接入真实 Redis 跟踪；复制账号、图片存储配置、退订入口、通知模板、OAuth 注册邀请码和运维健康入口补齐对应后端链路。
- 补齐合并后调用链：Anthropic `max_tokens` 对应 Responses incomplete 终态；Live 保留原始审计上下文，同时向旧审核适配器转换 instructions；API 密钥 IP 校验读取运行期设置；共用 OpenAI 选择器保留有新鲜用量证据时的额度恢复路径及冷却、权限和计费检查。兼容 Gemini 图片的 API-key 路径继续跳过 Codex 额度恢复，禁用或受限场景保持 503。

## 本地伪装与保护

- 默认 Claude CLI `2.1.119 (external, sdk-cli)` / Stainless `0.81.0` 及动态架构保持已发布基线；运行期版本配置能力合入；自动同步适配为默认关闭，缺失配置和读取错误均不启动版本跟随，显式开启与手动配置仍可使用。
- 所有 Claude OAuth 请求继续锁定本地指纹，包括真实 CLI 透传；每次请求只取一次 UA，同步用于出站头和 billing 版本。
- 保留身份注入、session masking/header、TLS 指纹、工具 ID/name 映射与强制 tool_choice、usage/cache 合成、请求 ID、错误脱敏、抓包和 first meaningful 观测。
- 保留本地缓存断点选择优先级，再执行上游 TTL 顺序修正。显式兼容性 beta 按客户端请求转发，未把实验性 beta 加入默认指纹。
- OpenAI 原始 encrypted_content 不作为 Anthropic 签名输出；完整链路仍由 gcr 的签名池负责。带明确 Anthropic 思考封装标记的协议回传只恢复封装内原始签名。
- 前端默认代理、伪装/header 编辑、抓包入口、紧凑管理布局及 relay 禁用上游二进制在线覆盖更新规则保留。

## 数据库和部署边界

新增五个 SQL 迁移：审计 engine_meta、自定义 reasoning effort 倍率、提现 operation_id、充值 bonus_amount、TypeSafe 平台约束。历史迁移内容保持不变。

`239` 会转换分组 JSON 定价字段，回退到 v2.32 必须同时核对定价数据兼容性，不能只凭新增列判断二进制回滚安全。部署前留存数据库、旧程序和配置，并验证迁移及重复执行。

本次目标为备用生产测试。部署目标、已执行验证、程序 hash 与回滚位置记录在工作区发布报告；主生产不属于本次发布范围。
