# sub2api 2.32.0-relay

## 合并范围

- 分支：`codex/sub2api-v2.32`，独立工作区 `sub2api-v2.32`。
- 发布基线：`codex/sub2api-v2.31` / `b802f485266dcbb7156ae4e383e35c6bb1cac2d6`。
- 上游：`Wei-Shaw/sub2api` 最新 main `efe9aab1e4ec89a42ba45e8dac20e882c5409a6a`（2026-09-17，VERSION 0.2.5）。
- 合并自 `4726bdd08b` 以来全部 158 个提交，保留双方历史。上游拆分实现按函数移植到本地布局；本轮新增的 89 个后端函数/类型声明无遗漏。
- 原始 `sub2api` 目录的旧分支及两处未提交工具协议改动保持原状。v2.31 已有同方向的 deferred-tool no-op，版本分支沿用已发布基线。

## 主要合入内容

- Responses 从 done/terminal 事件恢复缺失正文；保留引用、工具配对、流式结束事件和缓存计费。
- DeepSeek 工具结果图片和并行输出顺序；Lite namespace 回传；OAuth 输入元数据清理；取消请求后持久化 response affinity。
- WS ctx_pool 容量系数和等待者重选：保留会话连接的池容量按并发数 × 系数计算并受 hard cap 限制（默认系数 5），在飞请求仍受账号并发槽限制；替换本地 v2 曾把两种容量等同的逻辑。Codex 配额规范窗口与最大上下文、compact 默认模型 gpt-5.5 同步合入。
- Gemini 2xx 带内错误归因与模型列表；Antigravity 混合工具、SSE 分隔、账号隔离缓存及 attribution 清理。补齐历史上已存在但未调用的 project ID 配置 fallback，并在缺少必需项目时本地拒绝。
- 暂停但 active 的 OAuth 账号继续按到期策略刷新，不恢复其调度状态；非 active、KYC/永久错误账号仍排除。Ollama 429 异步探测与 CAS 冷却更新。
- 订阅批量操作和事务行锁；密钥批量编辑及供应商筛选；兑换分页；代理凭据显式清空；用量汇总查询与全平台统计；登录、支付、表单与交互修复。
- grpc 及相关依赖更新；保留本地 Wire 工具依赖。

## 伪装与本地功能

- 锁定的 Claude CLI 2.1.119 / Stainless 0.81.0 指纹、动态架构、会话 masking/header、默认 mimic beta 与 v2.31 保持一致。
- 上游新增 beta 常量、显式 beta 条件支持及无 beta 字段清理合入；不把未抓包确认的 thinking-binding/mid-conversation beta 自动追加到本地默认指纹。
- OpenAI encrypted_content 不伪装成 Anthropic signature_delta。签名仍由完整 gcr 链路负责，直连 sub2api 测试不代表 cctest 签名验证。
- 保留本地身份注入、工具 ID、usage/cache 合成及隔离、first meaningful 观测、错误脱敏、请求 ID 和流量抓取。
- 修复上游 quota 窗口判定依赖百分比指针别名、与本地百分比规范化复制冲突的问题；保留 used% 语义，并覆盖窗口反转、缺少 reset 字段和百分比相同的边界。
- 保留 Fast 默认过滤；新增 missing tier force_priority 仅在显式配置策略时生效。
- 保留管理界面的默认代理、Header/伪装工具、抓包、紧凑布局，以及 relay 版本禁用上游在线覆盖更新的保护。

## 验证结果

- 后端单元回归：55 个测试包通过，另 54 个包无测试；19,394 个通过事件（含子测试）、7 个跳过、零失败。最后的 Claude 配置错误脱敏补丁另经定向回归通过。
- 本地 PostgreSQL / Redis 集成：暂停 OAuth 分页、冷却更新 CAS 及兑换分页/用户隔离通过。
- 前端：293 个测试文件、2,097 个用例通过；类型检查、语言文案检查和生产构建通过。
- 页面验证：1440、768、390 宽度及相关弹窗共 12 个截图场景，无横向溢出或运行时错误。
- 伪装/本地功能守卫 7/7 通过；嵌入前端测试和 Linux amd64 静态构建通过。
- 尚未执行本版的备用环境推理测试和完整 gcr 签名链路 cctest，以上结果不代表其分数。
